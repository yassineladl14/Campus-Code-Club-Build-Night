# Campus Code Club Build Night

A responsive event landing page built with HTML and CSS for a Campus Code Club build night.

## Preview

Open `index.html` in a browser. The page uses `style.css` for its layout and styling.

## What it demonstrates

- Semantic page sections and navigation links
- Flexbox layouts and responsive breakpoints
- Speaker cards, event details, and a contact form layout
- Keyboard focus indicators and labeled form fields

The contact form is a visual demo and does not send messages yet. Connect it to a form service or a backend before presenting it as a working contact form.
